IP Phone Provisioning Guide

Use the following settings when configuring Yealink, Grandstream, or other LDAP-compatible IP phones:

LDAP1 Title              :RCM7021
LDAP1 Server             :<PBX IP Address>
LDAP1 port               :389
LDAP1 Base               :{{ settings.base_dn }}
LDAP1 Use SSL            :0
LDAP1 Version            :3
LDAP1 Username           :{{ settings.username }}
LDAP1 Password           :{{ settings.password }}
LDAP1 Name Attr          :cn sn
LDAP1 Tel Attr           :telephoneNumber
LDAP1 Mobile Attr        :mobile
LDAP1 Other Attr         :other
LDAP1 Sort Attr          :cn
LDAP1 Displayname        :cn
LDAP1 Number Filter      :(|(telephoneNumber=%)(mobile=%)(other=%))
LDAP1 Name Filter        :(|(cn=%)(sn=%))
